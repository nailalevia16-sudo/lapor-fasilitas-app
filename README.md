# 📱 Lapor Fasilitas App

Aplikasi Android untuk sistem pelaporan fasilitas sekolah yang dibuat menggunakan **MIT App Inventor** dan terhubung dengan **Firebase Realtime Database**.

## 📂 Isi Repository
- `LAPOR_FASILITAS.aia` : File sumber (*source code*) proyek MIT App Inventor. Kamu bisa mengimpor file ini ke [MIT App Inventor](https://ai2.appinventor.mit.edu/) jika ingin mengedit atau melihat blok kodenya.
- `LAPOR_FASILITAS.apk` : File instalasi aplikasi Android yang siap di-download dan di-install langsung di HP.
- `lapor-fasilitas-app-default-rtdb-export.json` : Cadangan data / struktur Firebase Realtime Database.

## 🛠️ Cara Penggunaan
1. **Install Aplikasi**: Download file `LAPOR_FASILITAS.apk` di perangkat Android lalu pasang aplikasinya.
2. **Edit Proyek**: Buka MIT App Inventor, pilih *Projects -> Import project (.aia) from my computer*, lalu pilih file `LAPOR_FASILITAS.aia`.
